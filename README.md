# archives-sombres

Chaine de production de la chaine TikTok/Instagram "Archives Sombres" (histoire sombre vraie, en francais).

- `pipeline/render.py` : montage (images fixes + voix + sous-titres animes) en MP4 1080x1920. Voir l'en-tete du fichier et `pipeline/exemple-spec.json`.
- `scripts/` : scripts valides (un fichier par video).
- `videos/` : MP4 publies. Chaque fichier est accessible par un lien direct `https://raw.githubusercontent.com/kylliann-larcher/archives-sombres/main/videos/...` pour la programmation Metricool.

Regle : aucune voix ElevenLabs ni publication avant validation du script par Kylliann.
